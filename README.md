# Kemp EVB workshop

A hands-on introduction to the Kemp reaction and empirical valence bond (EVB). Open the [public workshop](https://nd7996.github.io/Kemp-EVB-Workshop/) or open kemp_evb/index.html from a clone.

Start with the short comparison of MD, QM/MM MD, and EVB, then follow the reaction and use the saved browser activities. If you have a Linux computer, the optional calculation is explained in kemp_evb/calculation/README.md.

The paper uses Q6 for EVB. The short example uses OpenMM and EVBOpenMM for a five-atom, imposed geometry path. It is a software demonstration, not a physical free-energy calculation.
