# Kemp EVB workshop

Open the **[updated public workshop](https://nd7996.github.io/Kemp-EVB-Workshop/?v=energy-gap)** to learn EVB, compare the actual Q6 and OpenMM protocols, and run the full-enzyme calculation.

The **[installation and run section](https://nd7996.github.io/Kemp-EVB-Workshop/?v=energy-gap#linux)** now runs the complete 6,330-atom OpenMM system, from relaxation through mapping production and profile analysis. The five-atom illustration is a separate optional example.

[Full-enzyme guide](kemp_evb/full_enzyme/README.md) · [Bundled EVBOpenMM source](EVBOpenMM/) · [Saved full-enzyme profile](https://nd7996.github.io/Kemp-EVB-Workshop/viewers/full_enzyme_recorded_profile.html)

The current model is an adaptation with changed droplet electrostatics, not validated native-Q6 or published-barrier reproduction. The archived 9.57 kcal/mol estimate is parameter-conditional; the paper's 13.2 ± 0.6 kcal/mol Q6 reference is shown separately.
