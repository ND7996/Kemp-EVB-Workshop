# Kemp EVB hands-on

Open the [workshop website](https://nd7996.github.io/Kemp-EVB-Workshop/) or open `kemp_evb/index.html` from a clone. It follows three parts: what EVB is, what the Kemp example shows, and a set of hands-on exercises.

The saved browser exercises need no installation. For the optional short calculation on Linux, use the commands in [`kemp_evb/calculation/README.md`](kemp_evb/calculation/README.md).
