# Kemp EVB Workshop

Open the [public workshop website](https://nd7996.github.io/Kemp-EVB-Workshop/) for the paper overview, reaction mechanism, EVB/OpenMM comparison and practical exercises.

The complete workshop source and supporting files are in [`kemp_evb/`](kemp_evb/). To use it offline, open [`kemp_evb/index.html`](kemp_evb/index.html) in a browser and keep the folder structure intact so figures and interactive exercises load.

GitHub Pages publishes only `kemp_evb/` as the website. The deployment workflow is in [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml).
