# Kemp EVB Workshop

Open the [public workshop website](https://nd7996.github.io/Kemp-EVB-Workshop/). The workshop source files are in [`kemp_evb/`](kemp_evb/); to use them offline, open [`kemp_evb/index.html`](kemp_evb/index.html) in a browser.

The GitHub Actions workflow publishes the workshop page from that folder.
