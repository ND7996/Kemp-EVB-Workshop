# Kemp EVB workshop

Start with the [public workshop](https://nd7996.github.io/Kemp-EVB-Workshop/) or open [`kemp_evb/index.html`](kemp_evb/index.html) from a clone. The page introduces EVB, explains the Kemp reaction, and links to the parameter scan.

The scan compares 25 parameter combinations, including the archived baseline and five barrier-matched examples. It shows how α and H₁₂ affect the profile and reaction free energy using saved OpenMM energies. Choosing an example does not start a simulation.

For the separate optional Linux calculation, follow [`kemp_evb/calculation/README.md`](kemp_evb/calculation/README.md).
