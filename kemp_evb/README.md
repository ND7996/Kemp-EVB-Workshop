# Kemp reaction hands-on

Open [`index.html`](index.html) or visit the [public workshop](https://nd7996.github.io/Kemp-EVB-Workshop/). The page explains the EVB idea and the Kemp reaction, then links to the parameter scan.

In the scan, choose among 25 parameter combinations, including the archived baseline, plus five barrier-matched examples. Compare the profiles and reaction free energies to see how α and H₁₂ affect the result. These are saved-data examples; choosing a setting does not launch a simulation.

For the optional Linux calculation, follow [`calculation/README.md`](calculation/README.md).
