# Kemp EVB workshop

Open the [public workshop website](https://nd7996.github.io/Kemp-EVB-Workshop/) or, for offline use, open [`index.html`](index.html) in a browser. It includes the paper overview, reaction, EVB/OpenMM comparison, slides and interactive practical. No installation is needed to follow the saved examples.

For the optional live exercises, see [`guides/SETUP.md`](guides/SETUP.md) and [`guides/HANDS_ON.md`](guides/HANDS_ON.md).
